Install

インストール手順

ダウンロード後、以下の手順でインストールできます。

macOS

  1. 1ダウンロードした .dmg ファイルを開きます
  2. 2アプリアイコンを Applications フォルダにドラッグします
  3. 3Launchpad から Contribution Arc を起動します

Windows

  1. 1ダウンロードした .exe ファイルを実行します
  2. 2インストーラの指示に従ってインストールします
  3. 3スタートメニューから Contribution Arc を起動します

セキュリティについて

macOS は Notarization 済み、Windows はコード署名済みです。インストール時に警告が表示されることはありません。
