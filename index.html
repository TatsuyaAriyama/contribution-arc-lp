Product

学習時間と GitHub の積み重ねを、ひとつの画面で

記録した時間も、コミットも、PR も。バラバラだった学びの痕跡が、ひとつのダッシュボードに集まる。

Silent Workspace

話さなくても、隣にいる安心感

同じ時間を、誰かと静かに過ごす。声は要らない。集中している姿そのものが、もう励まし。

For Teams

組織の学習を、定量的に見守る

招待リンクでメンバーを集めれば、学習時間と GitHub 貢献がチーム単位で集計される。マネジメントに必要な指標を、煽らずに可視化する。

  • 学習トレンド

    直近12週間の学習時間を週次バーで表示。前週比（▲▼%）で勢いの変化を一目で把握できる。

  • 学習トピック内訳

    チームが実際に何を学んでいるかをトピック別に集計。各メンバーの記録色に連動し、どの領域に時間が投じられているかが見える。

  • 期間サマリー

    期間内の総学習時間と記録した人数を集計。組織全体の学習量を、定量的に把握できる。

Features

Contribution Arc にできること

学びの流れを支える、3つの仕組み。

  • 学習記録の可視化

    時間・教材・ジャンルで記録。グラフで積み上げを実感

  • GitHub 連携

    コミット・PR・Issue を貢献グラフとして表示。コードでの貢献も学習記録に

  • 静かなコミュニティ

    煽らないタイムライン。仲間の学びをそっと感じる

How it works

使い始め方

3ステップで、学びの記録を今日から残せる。

  1. STEP 01

    ダウンロードしてインストール

    macOS / Windows のデスクトップアプリ、または Web 版から。

  2. STEP 02

    GitHub で登録

    GitHub アカウントと連携すれば、コミット・PR・Issue が自動で貢献グラフとして表示される。

  3. STEP 03

    学習を記録、仲間とつながる

    今日の積み上げを残し、フォロー中の人の流れを眺める。
