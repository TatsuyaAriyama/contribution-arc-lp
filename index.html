Contribution Arc

学習が続くを設計する

エンジニアの学習・貢献を、静かに積み上げる。 GitHub の草と学習記録を一つの場所で。

Features

Contribution Arc にできること

学びを積み上げる、その邪魔をしないための4つの機能。

  • 学習記録の可視化

    時間・教材・ジャンルで記録。グラフで積み上げを実感

  • GitHub 連携

    コミット・PR・Issue を草として表示。コードでの貢献も学習記録に

  • 静かなコミュニティ

    煽らないタイムライン。仲間の学びをそっと感じる

  • Silent Workspace

    誰かと一緒に作業する空間。話さなくても、隣にいる安心感

How it works

使い始め方

3ステップで、学びの記録を今日から残せる。

  1. STEP 01

    ダウンロードしてインストール

    macOS / Windows のデスクトップアプリ、または Web 版から。

  2. STEP 02

    アカウント作成

    GitHub 連携で、すぐに草と学習記録を一つの場所に。

  3. STEP 03

    学習を記録、仲間とつながる

    今日の積み上げを残し、フォロー中の人の流れを眺める。
