Silent Workspace

話さなくても、隣にいる安心感

同じ時間を、誰かと静かに過ごす。声は要らない。集中している姿そのものが、もう励まし。

For Teams

チームの学びを、可視化する

招待リンクで集まったメンバーの学習が、ひとつのダッシュボードに集約される。煽らず、静かに、組織の学習量を定量化する。

  • 学習トレンド

    直近12週間の学習時間を週次バーで表示。前週比（▲▼%）で勢いの変化を一目で把握できる。

  • 学習トピック内訳

    チームが実際に何を学んでいるかをトピック別に集計。各メンバーの記録色に連動し、どの領域に時間が投じられているかが見える。

  • 期間サマリー

    期間内の総学習時間と記録した人数を集計。組織全体の学習量を、定量的に把握できる。

Features

Contribution Arc にできること

学びを積み上げる、その邪魔をしないための3つの機能。

  • 学習記録の可視化

    時間・教材・ジャンルで記録。グラフで積み上げを実感

  • GitHub 連携

    コミット・PR・Issue を草として表示。コードでの貢献も学習記録に

  • 静かなコミュニティ

    煽らないタイムライン。仲間の学びをそっと感じる

How it works

使い始め方

3ステップで、学びの記録を今日から残せる。

  1. STEP 01

    ダウンロードしてインストール

    macOS / Windows のデスクトップアプリ、または Web 版から。

  2. STEP 02

    アカウント作成

    GitHub 連携で、すぐに草と学習記録を一つの場所に。

  3. STEP 03

    学習を記録、仲間とつながる

    今日の積み上げを残し、フォロー中の人の流れを眺める。
